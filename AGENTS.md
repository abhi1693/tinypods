# Working in TinyPods

Read [CONTRIBUTING.md](CONTRIBUTING.md) for the shared engineering guidance. It applies to agents and human contributors; the [README](README.md) contains setup/check commands and the [API guide](apps/api/README.md) covers HTTP contracts.

Use the guidance with judgment and the scope of the active issue. Keep behavior, tests and documentation aligned, preserve operator data, and describe material deviations or unresolved limitations in the PR. This file links to the shared guidance rather than maintaining a second standards checklist.
